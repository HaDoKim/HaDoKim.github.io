이차전지의 성능을 항목별로 계측하고, 그 결과로 양불을 판정하는 검사 장비입니다.

## 맡은 일

**계측기 인터페이스 개발.** 검사 항목마다 다른 계측기가 붙었고 통신 방식도 RS232와
TCP/IP로 갈렸습니다. 계측기별 통신 코드를 각각 개발하되 상위에서는 같은 방식으로
다루도록 정리했습니다.

**PLC 통신 API 개발.** 장비 구동부와의 신호 인터페이스를 개발했습니다.

**계측 데이터 저장 구조 개발.** MariaDB를 사용해 검사 이력을 남기는 구조를 만들었습니다.
검사 장비는 판정 결과만 내고 끝나는 게 아니라, 나중에 "이 셀이 왜 불량으로 나왔는지"를
되짚을 수 있어야 합니다. 항목별 원시 계측값을 함께 보관하도록 설계했습니다.

**검사 결과 확인 UI 개발.** 항목별 데이터를 조회하는 화면을 개발했습니다.

## 사용 기술

Visual C++ / MFC, C#, MariaDB, RS232 · TCP/IP 통신, PLC 통신
