LED를 측정하고 분류하는 두 장비를 5년에 걸쳐 개발했습니다. Tester가 특성을 측정해
등급을 매기면, Handler가 그 등급대로 패키지를 분류하는 구조입니다.

## LED Tester

LED의 전기적·광학적 특성을 측정하고, 분류 기준에 따라 등급을 나눈 뒤 그 정보를 분류
장비로 보내주는 장비입니다.

단채널부터 다채널, 고출력용, AC 측정용, 테이핑 연계용까지 여러 기종을 개발했습니다.
기종마다 측정 항목과 채널 수가 달라, 측정 항목을 사용자가 직접 설정하는 프로그램을
별도로 만들어 기종이 늘어날 때마다 코드를 새로 짜지 않아도 되게 했습니다.

- 측정 항목 설정 프로그램 개발
- 장비 가동 프로그램 개발
- MES 인터페이스 개발

## LED Handler

LED 패키지를 측정 가능하도록 접촉시키고, 등급이 정해진 패키지를 지정된 위치로
분류해주는 장비입니다.

- 운영 UI 프로그램 개발
- PC 기반 Motion · I/O 제어
- 패키지 접촉부 제어 로직 개발
- 등급별 분류 로직 개발
- MES 인터페이스 개발

## 사용 기술

Visual C++ / MFC, Motion · DIO 제어, MES
